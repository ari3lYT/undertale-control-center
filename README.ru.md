# Undertale Control Center

[English README](README.md)

Локальный браузерный менеджер сохранений, истории, диагностики и опциональной live-связи для Steam-версии **UNDERTALE** под Linux.

Программа слушает только `127.0.0.1`, автоматически находит активную установку Steam и папку сохранений по имени сборки GameMaker, синхронно обновляет связанные файлы, делает защитные снимки и объясняет изменения обычным языком.

## Возможности

- структурированный редактор `file0`, `file9`, `undertale.ini`, `config.ini`, файлов геноцида и остальных файлов, которые может создать игра;
- синхронная запись значений, которые сама UNDERTALE меняет вместе, с проверкой и предпросмотром конфликтов;
- справочники предметов, телефона, комнат, сюжета, FUN, бонусной версии и всех 512 глобальных флагов;
- слоты, пресеты, полная очистка прохождения, автоматические бэкапы, смысловые diff и откат;
- live-панель, таймсплиттер сюжетных этапов, журнал сохраняемых полей памяти и журнал ввода при установленном игровом мосте;
- hot-изменение FUN/флагов и live-загрузка полного набора файлов вне боя и диалога;
- настройки WASD, Z/X/C, встроенного debug, логирования и частоты мониторинга;
- никаких сторонних Python-пакетов и облачных сервисов.

## Требования

- Linux;
- Python 3.10 или новее;
- легальная Steam-копия UNDERTALE.

Редактор файлов, слоты и откаты работают без модификации игры. Мониторинг памяти, runtime-журнал, переключатели WASD/ZXC и hot-загрузка требуют опционального моста из [`game-module/README.md`](game-module/README.md).

## Быстрый запуск

### Готовые Linux-сборки

Скачай нужный файл из [последнего релиза GitHub](https://github.com/ari3lYT/undertale-control-center/releases/latest):

- `undertale-control-center_VERSION_amd64.deb` — для Debian, Ubuntu, Mint и совместимых систем: установи пакет и открой **Менеджер Undertale** из меню приложений;
- `undertale-control-center-vVERSION-linux-x86_64.tar.gz` — портативная версия: распакуй архив и запусти `./undertale-control-center`.

В сборку уже входят Python и все файлы менеджера. Самой UNDERTALE и модифицированного `game.unx` внутри нет.

### Запуск из исходников

```bash
git clone https://github.com/ari3lYT/undertale-control-center.git
cd undertale-control-center
./start.sh
```

Откроется <http://127.0.0.1:8765>. Запуск без автоматического открытия браузера:

```bash
python3 server.py --no-browser
```

Проверка тестов:

```bash
python3 -m unittest discover -v
```

## Как программа защищает сохранения

- Сервер доступен только с этого компьютера и отклоняет изменяющие запросы с внешних origin.
- Перед каждой записью создаётся восстановимый снимок.
- Хеш предпросмотра не даёт применить план к уже изменившимся файлам.
- `file0`, `file9` и сводные INI меняются единым набором, пока пользователь явно не включит независимый режим.
- Live-команда привязана к текущей сессии, живёт 30 секунд и ждёт безопасного состояния вне боя и диалога.
- Произвольная комбинация сюжета и флагов всё равно может описывать состояние, которого в игре не бывает. Читай предпросмотр конфликтов и учитывай Steam Cloud.

Данные менеджера, слоты и история лежат в `~/.local/share/undertale-control-center`. Папка игровых сохранений определяется автоматически внутри `~/.config` по активной сборке.

## Поддерживаемые системы

Этот релиз рассчитан на нативную Linux-сборку GameMaker из Steam, включая актуальную юбилейную сборку и доступные в ней бонусные варианты. Автопоиск для Windows и macOS пока не реализован.

Интерфейс переключается между русским и английским кнопками `RU / EN` в верхней панели. Выбранный язык сохраняется в браузере. Подробные описания флагов, комнат и сюжетных этапов, извлечённые из установленной локализации игры, могут оставаться на языке этой сборки.

## Правовая информация

Это неофициальный фанатский инструмент, не связанный с Toby Fox, 8-4 или Valve. В репозитории нет исполняемого файла игры, `game.unx`, музыки, спрайтов, дампа диалогов или других коммерческих ресурсов. Исходники опционального моста применяются только к собственной копии пользователя.
